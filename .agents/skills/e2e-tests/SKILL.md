---
name: e2e-tests
description: Write and run end-to-end tests from a spec's acceptance criteria. Use only when the user asks.
disable-model-invocation: true
---
1. Read the spec; list each acceptance criterion.
2. Show a test plan (one test per criterion) and wait for approval.
3. Write tests with the project's existing framework, run them, report results.
4. Fix test bugs only; report product bugs, don't fix them.
